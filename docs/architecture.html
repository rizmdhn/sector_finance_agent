IDX Portfolio Agent Architecture

Multi-agent AI analyst for Indonesian stocks on the Sectors API: asks before it spends, shows how it answered

Agents

  • • Chief Orchestrator delegates to 4 specialists (Strands SDK)
  • • Per-user, per-role model tiers (Anthropic or OpenAI)
  • • Holdings kept as one saved portfolio, updated on buy/sell
  • • Risk & Evidence officer can review an answer

Sectors API, credit-aware

  • • Ticker list + index membership stored: LQ45 questions cost 0
  • • Reports cached per section, invalidated by data epochs
  • • Stale prices fetched per stock, only after approval
  • • 429: retry, and daily close resumes from the failed page

Guardrails & observability

  • • Server-side credit gate: the model can't approve itself
  • • Read-only tools: no trade execution
  • • Run limits (40 turns, 400k tokens), not-advice notice
  • • Every reply traced in Phoenix; trace drawer per answer
